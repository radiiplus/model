# Data Sources and Curation Landscape (Batch 2)

Checked 2026-11-23. The comparison below is based on pinned source snapshots when a canonical code repository exists, plus the currently visible official dataset cards/papers. No corpora, model weights, or benchmark packages were downloaded. Dataset cards can change; record a card revision/SHA and license text at the time of any later acquisition.

## How to read the evidence

- **Paper claim** describes a result reported by the authors under their model, data, token budget and evaluation. It does not establish universal data value.
- **Repository/card claim** describes a release or result as presented by its maintainers.
- **Source observation** describes code/config paths inspected at a pinned commit.
- **Our measurement** refers only to `experiments/fixtures/tiny_corpus.jsonl` and the standard-library experiment; it says nothing about web-scale performance.

“High value” cannot be inferred from fluency, classifier score, domain label, source prestige, or dedup rate alone. A useful training corpus must improve held-out task capability and language coverage per token/compute without unacceptable rights, privacy, contamination, safety, or domain-representation cost. Unique facts, rare identifiers, nonstandard styles, code and math need explicit retention checks because generic prose-quality heuristics can erase them.

## Dedup method comparison

| Method | Strength | Failure/cost | Local use |
|---|---|---|---|
| Exact normalized hashing | Fast, deterministic; reliable for byte/whitespace/case-normalized copies. | Misses edits, boilerplate variants and paraphrases. | Keep as first inexpensive pass, with normalization rules versioned. |
| MinHash + LSH on word shingles | Approximate Jaccard overlap; scales through signature, bucket and cluster stages. | Threshold/gram choice creates false merges and misses; boilerplate can dominate; cluster representative choice can lose a better source. | Tiny shingle-signature prototype is useful; production parameters must be calibrated and quality/provenance-aware representative selection needed. |
| SimHash on shingles | Compact signature; Hamming threshold cheap to compare. | Short texts and generic overlap yield collisions; distance threshold is corpus dependent. | Tiny implementation included only as a comparison; do not extrapolate its thresholds. |
| Semantic embedding dedup | May identify paraphrases with low lexical overlap. | Encoder dependency, embedding cost, model bias and cluster threshold; can merge distinct statements sharing topic or vocabulary. | Deferred: no small validated embedding model installed, and installing/downloading one would confound the local experiment. |

## What stays undecided

No named corpus is selected as the training mixture. A code license is not a license for constituent text. Web extraction can preserve personal information; PII removal is imperfect. Language-ID thresholds and quality models can penalize dialects and low-resource languages. Toxicity classifiers may systematically over-filter identity terms. Educational scoring favors formal exposition and its own proxy benchmarks. Duplicate removal can lower repeated evidence but also discard rare facts, alternate formulations, software versions and naturally repeated common knowledge. All exclusions should retain a reason-coded manifest, source ID, content hash and transformation version.

## Source-stage observations

- **Extraction:** DataTrove's FineWeb example uses WARC input, URL filtering and Trafilatura HTML extraction configured for precision. Extraction errors and boilerplate decisions can systematically change content, so keep original document identifiers and extraction version.
- **Language ID:** DataTrove's default FastText language filter uses a confidence threshold (reported default 0.65); FastText and optional GlotLID choices add model dependencies. Store language and confidence, and audit confused pairs/dialects instead of silently dropping all uncertain text.
- **Quality and safety:** FineWeb's heuristics include line punctuation, short-line, duplicate-character and newline ratios. FineWeb maintainers describe avoiding gold-source quality classifiers due bias concerns and note that web data can contain harmful text. Dolma exposes taggers for regex/Presidio PII and classifiers/signals such as language and toxicity. These annotate risk; no filter fully removes PII or unsafe material, and false positives need review.
- **Deduplication and contamination:** FineWeb performs MinHash in stages and uses crawl-specific choices; RedPajama V2 releases exact and fuzzy duplicate signals; Dolma Bloom-filtering may have false positives and can mark documents or paragraph spans. Dolma supports data attributes for held-out-test decontamination. SlimPajama docs describe exact train/holdout decontamination before tokenization. Dedup before/after quality filtering can change which cluster representative survives; keep all member IDs and select representatives using a documented quality/provenance rule.
- **Mixture and packing:** Dolma's `mix` allows source selection/remixing after tagging and dedup; tokenization is a later operation. SlimPajama's published order shuffles/splits before tokenize/pack. Packing must be tokenizer-specific, preserve document boundaries where required, and avoid combining train and evaluation content. We did not run a packing experiment.

One direct check of the recorded SlimPajama README path at the claimed Cerebras Model Zoo SHA returned HTTP 404 in this pass. The summary is therefore marked as a source-audit lead and needs a fresh canonical path/revision check before implementation. ## Additional mixture research leads

- **RegMix** (arXiv 2024): proposes regression-based data-mixture selection and reports results on models up to 7B in its paper. The exact code path, license and independent reproduction were not audited here. Use as a source-review lead, not a selected recipe: [paper](https://arxiv.org/abs/2407.01492).
- **RegMix-D** (arXiv 2026 preprint): proposes dynamic mixture selection from proxy trajectories and reports large token-budget experiments in the abstract. This is especially recent; peer-review status, code/license, data details and reproducibility need verification before relying on its claims: [paper](https://arxiv.org/abs/2606.18663).
- DoReMi is described in the pipeline ablation section. Its proxy reweighting result is not the same intervention as curriculum scheduling; the proposed matched-token schedule experiment remains necessary.
