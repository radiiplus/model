# Structural World Dataset Audit

## Dataset Identity

seeds assigned by [`splits.py`](splits.py). The corrected dataset is in
[`dataset_v5`](dataset_v5/manifest.json); earlier generated directories in this
workspace are superseded exploratory versions. It contains 108
underlying worlds and 12,096 query/action/surface examples. The ground-truth
answers and structural targets come from the deterministic transition and
graph routines in [`generator.py`](generator.py); the neural model is not
used to create labels.

## World And Oracle

Every world has six named entities with color, capacity, and status
properties; directed ownership, control, dependency, containment, supply,
and transfer edges; rules and constraints; an initial active-edge state; an
optional action; and the resulting state. Each non-structured description
explicitly includes entity IDs and properties, rule and constraint IDs, and
initial-state status. Actions remove or add an edge, transfer ownership, or
change a property. The transition function produces the resulting state
without mutating the initial state.

Questions cover mixed ownership/control influence reachability, whether a
relationship remains after an action, a relationship invariant, and the exact
state delta. Reachability uses a visited set, so the held-out control cycle
terminates. Dependency edges remain acyclic. Relationship state changes are
computed first and all answer text is then rendered from that exact result.

The structure target is canonical compact JSON. Its `p` field gives entity
property order; `e` contains entity bindings and values; `t` maps one-letter
relationship codes to full types; `r` contains `[id, type-code, source,
target]` records; `u` and `c` contain rule and constraint identifiers; `i`
and `s` are initial/resulting states. Each state's `r` value is a bitstring
indexed by the top-level relationship table, and `p` contains property
overrides. The optional `a` value encodes the action. This avoids exceeding
the existing 1,024-token context on the harder graph patterns while retaining
all bindings, properties, constraints, and state changes. The 120 largest rows
by prompt-plus-target character count were tokenized; the largest sequence was
987 tokens against the 1,024-token context.

## Surfaces And Leakage Controls

Each world/action/query family has six representations: explicit structured
input, natural-language facts, directed paraphrases, reversed fact order,
irrelevant color details, and counterfactual action wording. Ownership wording
is direction-checked against graph endpoints. Entities and property values
vary by deterministic seed. Every representation and action variant of a
`world_id` stays in one partition.

Input, query, and natural-answer templates are manually authored in separate
per-split wording banks. Template IDs are prefixed with the split and the
integrity check rejects cross-split ID reuse. Answer wrappers also differ by
split. Structural JSON keys and relation-code protocol are intentionally
fixed because they define the machine-readable target, not a natural-language
answer template. Surface transfer therefore remains part of the held-out
evaluation; the explicit structured surface provides a less language-heavy
view of structural generalization.

## Split Interpretation And Limits

Train, validation, and in-distribution test use the same `staggered` graph
pattern with disjoint world seeds. The compositional set combines familiar
edge types into an ownership-to-control-to-dependency chain, an adjacency not
used in training. The held-out pattern set uses a convergent ownership/control
diamond and a directed control cycle. The counterfactual set evaluates
non-null alternate action types on distinct worlds.

These are small synthetic symbolic worlds with a few hand-written surface
families. The pattern test changes graph topology and wording partition
together, so natural-language scores alone cannot isolate rule learning from
surface-form transfer. Per-surface scores and the structured-input condition
should be reported. Results do not imply general reasoning or natural-world
understanding.

Reproduce the dataset with:

```sh
python3 -m research.structure.generator
```

The command refuses to overwrite an existing dataset directory.
