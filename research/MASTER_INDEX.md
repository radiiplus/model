## Project

## Master Decision Matrix

The [recursive reasoning research anchors](reports/recursive_reasoning_references.md) summarize looped Transformers, dual-state refinement, training-time refinement, external context, learned memory and test-time learning, with transfer limits for the proposed small-model experiments.

| Decision area | Current direction | Evidence strength | Gate before promotion |
|---|---|---|---|
| Core model | Fixed causal Transformer baseline; no hybrid | Strong for correctness mechanics, weak for capability | Licensed held-out text/task results; one-factor comparisons at matched parameter and compute budgets |
| Sequence mixer | Recurrent/SSM branch remains a research candidate | One educational recurrence failed exact copy; not a family comparison | Canonical CPU implementation, cached Transformer comparator, at least 3 seeds and target long-range task gain |
| Tokenizer/data | Keep byte path as coverage reference; BPE/Unigram candidates; no corpus/mixture chosen | Tiny fixtures show round-trip/compression and dedup mechanics only | Rights-cleared representative corpus, split/leakage audit, equal-byte and equal-compute downstream model comparisons |
| Optimization/post-training | AdamW and next-token loss baseline; concise SFT optional; no RL by default | Toy training/SFT mechanics; optimizer rates untuned; no natural-language capability evidence | Held-out transfer beyond template/problem families with regression and cost accounting |
| Memory/reliability | Optional lexical retrieval + evidence verification + abstention; no learned memory | Structured synthetic controller/verifier mechanics only | Human-adjudicated natural-language evidence set; supported precision/recall, risk/coverage and false-abstention gates |
| Inference | Preserve native FP32 reference and KV parity; no runtime/quant selected | Tiny PyTorch CPU profile only; INT8 export smaller but slower | Actual target device, validated exporter, held-out task noninferiority and complete RSS/latency profile |

The detailed numerical comparisons and explicit missing evidence are in [architecture_options.md](decisions/architecture_options.md). These directions are provisional research choices, not a single capability score.

Batch 13 verdict: **not ready for genuine pretraining or paid GPU rental**. Blockers are a cleared/versioned corpus and rights audit, a realistic contamination-audited held-out evaluation suite, tokenizer selection at model level, a production-capable trainer/data packer, and hardware-specific throughput/memory measurements. CPU mechanics development remains ready.
